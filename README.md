# YouTube Channels Data Analysis

## 📌 Project Overview

This project analyzes data from top YouTube channels to identify
patterns in subscribers, views, uploads, and geographic distribution.

The analysis was performed using Python and popular data analysis
and visualization libraries.

## 🎯 Objectives

- Identify channels with the highest subscribers
- Analyze channels with the highest views
- Compare upload activity across channels
- Analyze country-wise channel distribution
- Compare total subscribers and views by country
- Identify useful performance patterns

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Data Analysis Process

1. Data loading
2. Data inspection
3. Missing-value handling
4. Data cleaning
5. Data type conversion
6. Exploratory Data Analysis
7. Data visualization
8. Country-wise analysis
9. KPI analysis
10. Business insights

## 📊 Key Insights

- T-Series and Cocomelon are among the leading channels by
  subscribers and views.
- India and the United States have a strong representation among
  the analyzed channels.
- Upload activity varies significantly across channels.
- Country-level analysis shows differences in total subscribers,
  views, and uploads.

## 📈 Key Metrics

- Subscribers
- Total Views
- Total Uploads
- Views per Upload
- Channels by Country
